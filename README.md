# Regelwerke – Cross-LLM-Katalog

Öffentlich abrufbare, versionierte Regelwerke von Adalbert Pojda, gedacht
zum Laden durch Sprachmodelle (Claude, ChatGPT, Gemini u. a.) über eine
feste Raw-URL – siehe jeweiliges Regelwerk, Abschnitt "Veröffentlichung
und dauerhafter Zugriff".

Verwaltet als Teil des Agenten-Katalogs "Regula" (Projekt Agent-Marketplace).
Nutzungsbedingungen: siehe [LICENSE](./LICENSE) – öffentlich lesbar heißt
nicht automatisch frei kommerziell weiterverwendbar.

## Anweisung für ein Sprachmodell

> Lade vor der Erstellung, Bearbeitung oder Veröffentlichung eines Inhalts
> das passende Regelwerk aus diesem Repository über dessen Raw-URL. Wende
> die maschinenlesbaren Entscheidungsregeln (Abschnitt "Maschinenlesbare
> Regeln") verbindlich an. Verwende bei Unsicherheit die höhere
> Kennzeichnungsstufe.

## Pflege

Quelle der Wahrheit für Änderungen ist die jeweilige Datei in diesem
Repository. Bei jeder Änderung Versionsnummer und Stand in der Datei
aktualisieren.
